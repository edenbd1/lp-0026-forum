# Discord invite (#builder-hub) — draft, to post yourself

Hey all, I've built a forum app for Basecamp for LP-0026 and I'd love people to
actually use it.

No server anywhere: posts go over Logos Delivery, history is shared through
Logos Storage, and every post is signed and verified when it arrives. You can
post as yourself, under an alias, or fully anonymously (one-time key).

To try it in Basecamp 0.3.0:
1. Settings → Package Repositories → add
   https://raw.githubusercontent.com/edenbd1/logos-forum-catalog/main/logos-repo.json
2. Package Manager → Social → Logos Forum → Install
3. Open it and start a topic, or reply to one

Anything goes: questions about Logos, what you're building, privacy tools you
use. And if something breaks or feels clunky, tell me here, that's the most
useful thing you can do.
